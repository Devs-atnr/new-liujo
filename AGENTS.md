# Project Rules & Performance Guidelines

## Agent Performance & Response Guidelines
- Keep responses concise, direct, and actionable. Avoid unnecessary preambles and boilerplate explanations.
- Make targeted edits using precise replacements instead of rewriting entire files.
- Never read or analyze binary files (images, fonts, zip files).
- Keep changes localized to relevant Shopify theme Liquid files (`sections/`, `snippets/`, `templates/`, `layout/`, `assets/*.css`, `assets/*.js`).
